# DevCommunity - Specialized Social Networking Platform for Developers

## Description
DevCommunity is a specialized social networking platform designed for the developer community, facilitating connections, technical knowledge sharing, and collaboration. Built with modern technologies like Next.js (frontend), Node.js (backend), MongoDB (database), Socket.io (real-time communication), Multer (file upload), Redis (caching), and Amazon S3 (storage), the platform offers a professional environment with high performance, fast load times, and advanced technical features such as syntax highlighting for over 10 programming languages.
The project targets IT students, novice developers, experienced developers, and tech leads/managers, with an initial pilot at Can Tho University of Technology, later expanding to the Vietnamese developer community.


## Key Features

Professional Networking: Post sharing, messaging, friend connections, and group chats.
Technical Sharing: Syntax highlighting, tagging, and accurate content categorization.
High Performance: Page load under 2.5 seconds, support for 1,000 simultaneous users, 99.5% uptime.
Security: Utilizes modern encryption and authentication tools.
Real-Time: Notifications and chats via Socket.io.
Storage: Efficient file and data management.

## Installation Guide

Clone the repository: git clone https://github.com/ThanhDang1008/DevCommunity.git
cd devcommunity

Install dependencies for backend and frontend:
### Backend
cd backend
npm install

### Frontend
cd ../frontend
npm install

Set up environment variables (create .env files in backend and frontend based on .env.example).
Run the application:
### Backend
cd backend
npm run dev

### Frontend
cd ../frontend
npm run dev


Access the application at http://localhost:8888
